## ✨ Features

- **Responsive Design**: Fluid layout optimized for mobile, tablet, and ultra-wide desktop viewports.
- **Project Showcase**: Highlights flagship projects across distributed systems, fintech, quantitative trading, and cloud infrastructure.
- **Technical Arsenal**: Interactive badges and breakdown of languages, frameworks, and devops tooling.
- **Direct Resume Access**: Downloadable and viewable PDF resume directly linked.
- **Zero-Dependency Architecture**: Built using semantic HTML5, modern CSS3 (Flexbox/Grid), and vanilla JavaScript for sub-100ms load times.

## 🛠️ Local Development

Clone the repository and open in any browser:
```bash
git clone https://github.com/shamir-khan-dev/Personal-Website.git
cd Personal-Website
# Open index.html directly or serve locally:
python -m http.server 3000
```
Visit `http://localhost:3000` to preview changes.
